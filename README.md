🪐 Orbit Wars — Kaggle RL Competition · Rank 102

Real-time strategy Reinforcement Learning agent

An optimized, PyTorch-based RL agent built for the Kaggle Orbit Wars strategy competition, leading team NEXUS to a final rank of 102 with a top score of 1252. Uses a vectorized trajectory/intercept engine, a custom "Enemy Pressure" threat model, continuous collision avoidance, and adaptive strategy switching between 1v1 and 4-player matches — all running under a strict 1-second-per-turn compute budget.

Python PyTorch Kaggle Environments

🌡️ CoolPriority — FortyGuard Hackathon '26

AI-powered urban heat decision-support system

Combines FortyGuard hyperlocal temperature data, the CDC/ATSDR Social Vulnerability Index, population context, and transit locations into a normalized Cooling Priority Score. Simulates interventions (urban trees, cool roofs, cooling centers) and compares budget-constrained allocation policies (Need-First, Balanced, Reach-First) through an interactive Streamlit dashboard — turning raw heat data into explainable, actionable planning decisions.

Python Streamlit Geospatial Analysis FortyGuard API
